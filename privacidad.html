Política de privacidad

Obi Gmail · Última actualización: 12 de noviembre de 2026

Obi Gmail es un asistente personal de uso privado, creado y operado por Jhon Jairo Obando Rodríguez. No es un producto comercial ni está disponible para el público: su único usuario es su propietario.

1. Qué datos usa la aplicación

Cuando su propietario autoriza el acceso con su cuenta de Google, la aplicación puede acceder a:

  • Gmail: leer, resumir y clasificar correos; redactar borradores; y eliminar correos solo cuando el propietario lo confirma.
  • Google Calendar: consultar, crear y eliminar eventos del calendario.

2. Para qué se usan

Los datos se usan únicamente para responder las solicitudes que el propietario hace a su asistente (por ejemplo, "resume mis correos urgentes" o "¿qué tengo hoy en la agenda?"). No se usan para publicidad, perfilado, ni para entrenar modelos de inteligencia artificial.

3. Cómo se procesan y dónde se guardan

  • La aplicación se ejecuta en un servidor propio (Railway) con la plataforma de automatización n8n.
  • Para generar resúmenes y respuestas, el contenido necesario de cada consulta se envía a la API de Anthropic (Claude), que lo procesa para devolver el resultado.
  • El asistente conserva una memoria de conversación reciente para mantener el contexto, que puede incluir fragmentos de la información consultada. Esa memoria se almacena en una base de datos privada del propietario.
  • La aplicación no mantiene copias permanentes de los correos ni del calendario fuera de lo anterior.

4. Con quién se comparten

Los datos de Google no se venden ni se comparten con terceros, salvo con los proveedores técnicos mencionados arriba (Railway para el alojamiento y Anthropic para el procesamiento), y solo en la medida necesaria para prestar el servicio. El uso de la información recibida de las APIs de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

5. Seguridad

El acceso se realiza mediante OAuth 2.0: la aplicación nunca conoce ni almacena la contraseña de Google. Los permisos pueden limitarse o retirarse en cualquier momento.

6. Cómo revocar el acceso

El propietario puede retirar el acceso de la aplicación en cualquier momento desde myaccount.google.com/permissions. También puede solicitar la eliminación de la memoria de conversación almacenada.

7. Cambios en esta política

Si el funcionamiento de la aplicación cambia, esta página se actualizará y se indicará la fecha de la última modificación.
